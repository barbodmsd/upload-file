# Upload File

### description :

- This is a custom upload file with `Material Ui`
- With ability to show preview images
- Drag and Drop images
- Upload multiple images at once
- Show progress bar
- Show success message
- Remove images before upload

# How to use ?

1. Import the component in your file
2. Use the component in your JSX file
3. Send props `setImagesName` to get the imagesName after upload
4. Now you have the imagesName from the server
5. Easy peasy

- Hint : See the `App.jsx` file and you will get the all story
